📨 Message Flow: Product Search

1. User types search query in browser
2. Frontend sends AJAX request to Flask API (/api/query)
3. Flask calls ProductSearchA2UI module
4. Module sends "loading" update to A2UI Server
5. A2UI Server broadcasts to subscribed WebSocket clients
6. Frontend receives update, shows loading spinner
7. Module queries database/Hybris for products
8. Module sends "product_list" update to A2UI Server
9. A2UI Server broadcasts results to WebSocket clients
10. Frontend receives products, renders cards
11. Module sends "toast" notification (success)
12. Frontend displays toast message

Backend Example

# Python - Send Update
from modules.product_search_a2ui import ProductSearchA2UI

search = ProductSearchA2UI(
    session_id="user_123"
)

await search.send_search_results(
    products=products,
    query="laptop",
    total_count=25
)

Frontend Example

// JavaScript - Handle Update
a2uiClient.on('product_list', ({ data }) => {
    const products = data.products;
    displayProducts(products);
});

a2uiClient.on('loading_state', ({ data }) => {
    if (data.is_loading) {
        showLoader();
    }
});

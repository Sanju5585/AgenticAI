Image Validation

Resize & Optimize

• Image Size & Format

🤖 Step 3: AI Vision Analysis
Google Gemini Vision
gemini-2.5-flash-lite
→
Extract Metadata
Category, Type, Colors, Attributes
AI Analysis Output (JSON):
{
  "category": "Accessories",
  "product_type": "Sunglasses",
  "colors": ["black", "gold", "gray"],
  "attributes": ["aviator", "metal frame", "UV protection"],
  "keywords": ["sunglasses", "eyewear", "fashion", "aviator", "accessories"]
}
↓
🔍 Step 4: Product Search
Build Search Query
Use product_type (primary)
→
HANA DB Query
LIKE search on name & summary
→
Rank Results
Exact match priority
SQL Query:
SELECT PRODUCT_ID, PRODUCT_NAME, SUMMARY, PRICE, IMAGE_URL, CATEGORY_IDs
FROM SAP_PRODUCTS_COMMERCE_2211_V2
WHERE LOWER(PRODUCT_NAME) LIKE LOWER('%sunglasses%')
   OR LOWER(SUMMARY) LIKE LOWER('%sunglasses%')
ORDER BY relevance
LIMIT 5
↓
📦 Step 5: Return Results
Format Response
Product details + metadata
→
Normalize URLs
Rewrite media host if needed
→
Send to Frontend
JSON response with products

🎯 Search Strategy

  • Uses PRODUCT TYPE (not category)
  • Example: "Sunglasses" not "Accessories"
  • Prevents wrong results (watches vs sunglasses)
  • Falls back to keywords if type fails
  • LIKE-based text matching

🔒 Validation & Safety

  • Max file size: 4MB
  • Supported formats: JPG, PNG, WebP, GIF
  • Image integrity verification
  • Secure hash-based storage
  • Error handling at each step

🎨 Image Processing

  • Auto-resize to max 1024px
  • RGB conversion for consistency
  • K-means color clustering (5 colors)
  • Perceptual & Average hashing
  • Metadata extraction

🤖 AI Vision Capabilities

  • Google Gemini 2.5 Flash-Lite
  • Product category detection
  • Attribute extraction
  • Color identification
  • Keyword generation

💾 Database Integration

  • SAP HANA Cloud connection
  • Encrypted SSL connection
  • LIKE-based text search
  • Relevance-based ranking
  • Configurable result limit

📊 Response Format

  • Product ID, Name, Summary
  • Price & Category information
  • Normalized image URLs
  • Similarity score (0.8 default)
  • Image analysis metadata

🛠️ Technology Stack

Python 3.x Flask API Google Gemini Vision SAP HANA Cloud PIL (Pillow) NumPy scikit-learn imagehash hdbcli

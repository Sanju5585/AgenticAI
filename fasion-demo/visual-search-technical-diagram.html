📊 Request-Response Data Flow
1
HTTP POST Request
Endpoint: /api/visual-search
Content-Type: multipart/form-data
Parameters: file (binary), limit (optional, default: 5)
2
Server-Side Validation
Checks: File presence, MIME type (jpg/png/webp/gif), size ≤ 4MB
Failure: Returns 400 Bad Request with error message
3
Image Processing Pipeline
Operations: Load → Resize → RGB conversion → Feature extraction
Features: Size, format, dominant colors, phash, ahash
Cache: Save to image_cache/ with MD5 filename
4
AI Vision Analysis
Model: Google Gemini 2.5 Flash-Lite
Input: Structured prompt + PIL Image object
Output: JSON {category, product_type, colors, attributes, keywords}
Fallback: Switch to gemini-1.5-flash on error
5
Search Query Generation
Primary: product_type from AI analysis
Fallback: First keyword if product_type is generic
Strategy: Avoid broad categories like "Accessories"
6
Database Query Execution
Table: SAP_PRODUCTS_COMMERCE_2211_V2
Search: LIKE on PRODUCT_NAME and SUMMARY
Ranking: Exact match in name gets priority
Limit: User-specified (default: 5, fetches 2x for filtering)
7
Response Construction
Format: JSON with success, results array, metadata
Product Fields: ID, name, summary, price, image_url, category
Metadata: image_cache filename, AI analysis, feature data
HTTP Status: 200 OK (success) or 400/500 (error)

🔍 SQL Query Template
SELECT 
    p.PRODUCT_ID,
    p.PRODUCT_NAME,
    p.SUMMARY,
    p.PRICE,
    p.IMAGE_URL,
    p.CATEGORY_IDs
FROM 
    SAP_PRODUCTS_COMMERCE_2211_V2 p
WHERE 
    LOWER(p.PRODUCT_NAME) LIKE LOWER(?)   -- %sunglasses%
    OR LOWER(p.SUMMARY) LIKE LOWER(?)      -- %sunglasses%
ORDER BY 
    CASE 
        WHEN LOWER(p.PRODUCT_NAME) LIKE LOWER(?) THEN 1   -- Exact match priority
        ELSE 2
    END
LIMIT ?   -- limit * 2 for filtering

🚨 Error Handling Strategy
# Validation Errors (400 Bad Request)
- "No image file provided"
- "Image too large. Maximum size is 4MB"
- "Unsupported format. Use: jpg, jpeg, png, webp, gif"
- "Invalid image: [PIL error details]"

# AI Model Errors (with fallback)
try:
    model = genai.GenerativeModel("gemini-2.5-flash-lite")
except Exception:
    model = genai.GenerativeModel("gemini-1.5-flash")  # Fallback

# Database Errors (500 Internal Server Error)
- Connection failures → "Database connection error"
- Query errors → "Database search error"
- Returns empty results array on DB failures

# General Errors (500)
- "Unexpected error while running visual search. Please retry shortly."
- Full stack traces logged to console for debugging
